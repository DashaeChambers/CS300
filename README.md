# CS 300 Project Two: ABCU Advising Assistance Program

## Project Overview
This project is a C++ advising assistance program designed to help academic advisors at ABCU manage and look up Computer Science courses. The program reads course information from a CSV file and stores the data in a data structure for searching and displaying course information.

## Features
- Loads course information from a CSV file.
- Displays a list of courses in alphanumeric order.
- Allows users to search for an individual course by course number.
- Displays course titles and prerequisite course information.
- Handles invalid menu selections and course lookups.
- Provides a menu option to exit the program.

## How to Run
1. Open `ProjectTwo.cpp` in a C++ IDE, such as Visual Studio.
2. Build and run the program.
3. Select option `1` to load the course data file.
4. Enter the path to the CSV file when prompted.
5. Select option `2` to display the sorted course list.
6. Select option `3` to look up a course and its prerequisites.
7. Select option `9` to exit.

## Technologies Used
- C++
- Standard Template Library (STL)
- CSV file input
- Visual Studio

## Learning Outcomes
This project provided practice working with data structures, sorting, file input, searching, and input validation. It also demonstrated how algorithms and data structures can be used to organize course information and support academic advising.
